# Sales-Performance-Dashboard
Sales Performance Overview Dashboard
Project Overview
This project provides an end-to-end analysis of sales data, focusing on identifying key revenue drivers and optimizing pricing strategies. The dashboard serves as a comprehensive overview of business health, enabling stakeholders to make data-driven decisions based on regional, category, and seasonal performance.

Dashboard Preview
Key Insights
Seasonal Revenue Trends: Identified critical volatility in revenue, with specific dips in July and October that highlight potential areas for marketing intervention.

Category Performance: Visualized revenue distribution across product categories, identifying "Clothing" as the top performer.

Discount Effectiveness: Through scatter plot analysis, examined the impact of discounts on unit sales to determine if current pricing strategies are effectively driving volume.

Regional & Payment Distribution: Mapped revenue share across regions and analyzed preferred payment methods to understand customer purchasing behavior.

Technical Skills Applied
Data Preparation: Cleaned and transformed raw data using Power Query (M code) to ensure model accuracy and consistency.

Data Modeling: Built a robust data model to support multi-faceted analysis.

DAX Measures: Developed calculated measures to track Sales Revenue, Sales Volume, and Profit Margin.

Visualization Design: Designed an intuitive UI focused on executive-level readability and actionable insights.

Dataset
This analysis is based on the Sales Dataset available on Kaggle: https://www.kaggle.com/datasets/vinothkannaece/sales-dataset
